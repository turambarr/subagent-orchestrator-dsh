# 验收门

## 两层验收（先任务层，后实验层，不可跳）

**flash 级（任务层）**——缺一项打回，不进入结论：

- [ ] 执行完成（命令跑完，无超时/崩溃）
- [ ] 数字进容差（|测量 − 基准| ≤ 容差）
- [ ] 六段回报齐全（任务/方法/结果/证据/差值/偏差说明/未决）

**pro 级（实验层）**——由 pro 判读：

- 结果支持 / 否定哪个假设？
- 改参、换假设、还是结论成立？
- 是否进入下一轮，或阻塞？

## 四级门（证据强度递增，不可越级冒充）

| 级 | 手段 | 定义 |
|---|---|---|
| ① 可复现 | 同命令 → 同数字 | 执行本身的确定性 |
| ② 内部一致性 | 注入 → 恢复 | 平台自洽（不是"真实"） |
| ③ 跨实现交叉 | 两条独立路径对上 | 消除单实现偏差 |
| ④ 外部锚定 | 独立传播器 / 公开数据 | 唯一指向"真实"的证据 |

红线：**②③④ 逐级递进，低级不能冒充高级。** 尤其"内部一致性"永远不等于"物理真实"。

## 三条红线（一票否决）

1. 把**正向计算**说成"估计 / 恢复 / 找"（正向 ↔ 反演混淆）。
2. 把**内部一致性**说成"物理真实"（自洽 ≠ 真实）。
3. 把**验证仪器**（如离线匹配滤波）说成"接收机能力"。

任何 flash 回报或 pro 结论触及这三条之一，打回重写。
