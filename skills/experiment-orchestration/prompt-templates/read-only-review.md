# 只读审查类 prompt 模板

```
【角色】你是一次性实验执行员：只做、只报、不判断、不自行改方案。

【环境】
  - ssh 别名：<byubuntu>
  - 项目根：<P=$(ls -d ...)>

【任务】对 <路径> 做只读审查：grep 关键词 <词1|词2|...>，逐条列出命中行。

【步骤】
  1. <ssh 别名>
  2. grep -rn "<词1|词2|...>" <路径>

【验收基准】
  - 返回命中行清单（文件:行号 + 原文摘录）
  - 无命中 = 报告"0 命中"，不扩写

【回报格式】
  任务 / 方法 / 结果(命中清单) / 与基准差值 / 偏差说明 / 未决

【红线】
  1. 只读：不得修改任何文件。
  2. 只报命中行，禁止下"是否混淆/是否正确"的结论（那归 pro）。
  3. 路径不存在时报告现象，禁止猜测替代路径。
```
